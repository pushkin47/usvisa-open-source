# US Visa Open Source: Астана

Локальное приложение для мониторинга свободных дат и времени собеседования на AIS US Visa в Астане. Есть веб-панель, профили пользователей, фильтры дат, фоновый мониторинг и автоматическая запись на выбранные приоритетные даты.

Поддерживается только Астана: Казахстан, ID консульства `134`. Ограничение применяется в веб-панели, API настроек, браузерном входе и CLI. Внешних уведомлений и рассылок нет: результаты, ошибки и события доступны в локальной панели и консоли. Приложение не связано с посольством или оператором AIS.

## Что потребуется

- Python 3.12, Git и macOS или Linux. Windows напрямую не поддерживается: монитор использует `fcntl`; можно использовать Linux через WSL.
- Свой аккаунт на `ais.usvisa-info.com` с доступом к странице записи в Астане.
- Chromium для Playwright. Он устанавливается отдельной командой ниже.
- Доступ к сайту AIS из вашей сети. Proxy необязателен и по умолчанию выключен.

## Установка

Склонируйте этот репозиторий кнопкой **Code**, откройте его каталог в терминале и выполните:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m playwright install chromium
cp .env.example .env
chmod 600 .env
```

На Linux, если Chromium сообщает об отсутствии системных библиотек:

```bash
python -m playwright install --with-deps chromium
```

Команда `--with-deps` устанавливает системные пакеты и может запросить права администратора. Для видимого окна браузера нужен рабочий стол; на сервере используйте `USVISA_BROWSER_HEADLESS=true`.

## Первый запуск веб-панели

1. Откройте `.env` в текстовом редакторе. Заполните `USVISA_ADMIN_EMAIL` своим адресом и `USVISA_ADMIN_PASSWORD` уникальным паролем длиной от 12 символов. Это вход в локальную панель, отдельный от аккаунта AIS. Встроенного администратора и общего пароля нет.
2. Выполните:

   ```bash
   python src/web_app.py
   ```

3. Откройте [локальную панель](http://127.0.0.1:8765) и войдите с данными из `.env`. Не включайте фоновый мониторинг до настройки аккаунта.
4. Во вкладке **Пользователи** откройте настройки нужного пользователя. Введите его логин и пароль AIS, три адреса записи по инструкции ниже и сохраните. Город всегда **Астана**. Для одного аккаунта используйте профиль администратора.
5. В системных настройках оставьте `USVISA_BROWSER_HEADLESS=false`, если хотите видеть браузер. Запустите браузерный логин кнопкой панели. Скрипт откроет AIS, войдет и сохранит локальную сессию. CAPTCHA и MFA автоматически не обходятся; при их появлении завершите необходимое действие вручную в браузере.
6. Выполните одну проверку. Результат смотрите во вкладках с датами и логами. Пустой список дат означает, что сейчас доступных дат нет.
7. Для постоянного поиска установите нужному пользователю статус **поиск включен** и нажмите **Старт 24/7**. Новые зарегистрированные пользователи получают статус **не оплачен**: это только локальная метка доступа, платежной интеграции нет. Статус меняет администратор.

Если аккаунтов несколько, каждому задаются собственные адреса записи, учетные данные и состояние. Общие адреса во вкладке **Астана** используйте только для одного аккаунта; индивидуальные адреса имеют приоритет. Вкладка **Демо доступ** показывает синтетические данные и не проверяет AIS.

Панель слушает только `127.0.0.1`. Для удаленного доступа предпочтителен SSH-туннель. Не публикуйте этот локальный интерфейс напрямую в интернете. Данные AIS и сессии хранятся локально без шифрования на уровне приложения.

## Где взять адреса записи

После обычного входа в AIS откройте страницу записи своего аккаунта. В адресе будет ваш `schedule` ID. Не используйте номер из чужого аккаунта.

Формат адресов (замените `YOUR_SCHEDULE_ID` своим числовым ID):

```text
https://ais.usvisa-info.com/ru-kz/niv/schedule/YOUR_SCHEDULE_ID/appointment
https://ais.usvisa-info.com/ru-kz/niv/schedule/YOUR_SCHEDULE_ID/appointment/days/134.json?appointments[expedite]=false
https://ais.usvisa-info.com/ru-kz/niv/schedule/YOUR_SCHEDULE_ID/appointment/times/134.json
```

Поддерживается также языковой префикс `en-kz`. Все три адреса должны принадлежать одному `schedule` ID. Самый надежный способ проверить API-адреса: открыть инструменты разработчика браузера, вкладку **Network**, выбрать Астану и посмотреть запросы `days/134.json` и `times/134.json`. Для URL времени удалите параметр `date`: монитор добавит дату сам.

Для работы только из CLI заполните эти три поля в `.env`, а также `USVISA_LOGIN_EMAIL` и `USVISA_LOGIN_PASSWORD`. Для веб-панели используйте настройки пользователя, поскольку профиль хранится в SQLite и имеет приоритет над CLI-настройками.

## Автозапись

Монитор может реально отправить запрос на запись или перенос собеседования. Она включается, когда заданы приоритетные даты или периоды, на которые есть свободное время. Укажите число дней на подготовку и проверьте свой текущий статус записи перед включением.

Если нужны только наблюдение и просмотр слотов, оставьте приоритетные даты пустыми. Игнорируемые даты исключаются из поиска. После подтвержденной записи фоновый режим останавливает поиск для соответствующего пользователя.

## CLI и работа в фоне

После заполнения CLI-настроек в `.env`:

```bash
# Вход в AIS, сохранение сессии и одна проверка:
python src/usvisa_browser_login_and_run.py

# Одна проверка с сохраненной сессией:
python src/usvisa_appointment_monitor.py
```

Одна проверка учитывает сохраненный `next_check_at` и может завершиться без запроса, если еще не наступило время следующего запуска. Интервал реальных проверок выбирается между `USVISA_MIN_CHECK_INTERVAL_SECONDS` и `USVISA_MAX_CHECK_INTERVAL_SECONDS`, по умолчанию 60-300 секунд. Для длительной работы используйте **Старт 24/7** в панели. Закрытие процесса панели останавливает мониторинг.

`USVISA_MONITOR_AUTOSTART=true` запускает мониторинг при старте панели. Включайте его только после успешной ручной настройки. На macOS `USVISA_WEB_PREVENT_SLEEP=true` удерживает компьютер от сна во время мониторинга. CI проверяет код и не выполняет мониторинг аккаунтов.

## Необязательный proxy

Можно задать собственный `Proxy URL` в настройках пользователя или `USVISA_VPN_ENABLED=true` и `USVISA_VPN_PROXY_URL` для общего CLI-режима. Готовых VPN-подписок и инфраструктуры в проекте нет.

В `src/vpn_singbox_config.py` сохранен вспомогательный генератор конфигурации sing-box для совместимого JSON-списка VLESS Reality профилей. Он не требуется для обычной установки. Если используете его, задайте свою подписку и HWID, изучите `python src/vpn_singbox_config.py --help` и укажите выходной путь через `--output`. Автоматическое управление VPN на сервере в репозиторий не входит.

## Проверка установки

Тесты используют временные данные и локальный веб-сервер. Они не отправляют запросы в AIS и не бронируют собеседования:

```bash
python -m unittest discover -s tests
python -m compileall -q src tests
```

Браузерные тесты требуют установленного Chromium. Проверка реального входа, доступности слотов и записи зависит от вашего аккаунта и текущего интерфейса AIS. Локальные тесты не доказывают успешную запись на живом сайте.

## Хранение данных и типичные ошибки

- `.env` содержит настройки, `state/` содержит SQLite, cookies, профили браузера и логи. Эти файлы исключены из Git. Никогда не прикладывайте их целиком к issue или архиву проекта.
- Ошибка первого запуска с `USVISA_ADMIN_EMAIL` или `USVISA_ADMIN_PASSWORD`: заполните собственные данные в `.env`. Пароль администратора из `.env` повторно применяется при старте панели, если он задан.
- Ошибка о URL Астаны: проверьте страну `kz`, одинаковый `schedule` ID и ID консульства `134`.
- `401` или `403`: сессия могла истечь; повторите браузерный вход. При ограничении доступа со стороны сайта остановите мониторинг и проверьте вход вручную.
- `429`: сервис ограничил частоту запросов. Остановите мониторинг и увеличьте интервалы перед повторным запуском.
- Отсутствует браузер: повторите `python -m playwright install chromium` из активированной `.venv`.
- Страница или API AIS изменились: автоматизация может потребовать адаптации. Проект предоставляется без гарантии получения слота.

Не запускайте одновременно несколько экземпляров веб-панели с одной базой и профилем. Подробная сетевая трассировка и HTML-снимки могут содержать ваши персональные данные; держите их локально.
